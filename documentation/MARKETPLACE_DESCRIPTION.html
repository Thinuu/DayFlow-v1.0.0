DayFlow | Personal Finance and Daily Planner Android App

DayFlow is a comprehensive productivity and personal finance application for Android, built with modern development standards and designed following Google's Material Design 3 guidelines. This all-in-one solution combines daily habit tracking, financial management, budget planning, and intelligent insights into a cohesive, offline-first application.

Product Introduction

DayFlow helps users take control of their finances and daily routines through an intuitive, feature-rich Android application. Whether tracking expenses, managing budgets, building habits, or monitoring savings goals, DayFlow provides the tools needed for personal productivity and financial wellness.

Built with 100% Kotlin, Jetpack Compose, and Material Design 3, DayFlow represents modern Android development best practices with clean architecture, MVVM pattern, and Room SQLite for local data persistence.

Key Features

Finance Management

  • Multi-Account Tracking — Manage Checking, Savings, Credit Cards, Cash, and Digital Wallets with real-time balance updates
  • Account Transfers — Balance transfers with automatic dual-entry transaction logging
  • Custom Categories — Create personalized income and expense categories with custom icons and colors
  • Currency Selection — Choose from 12 supported currencies; preference is persisted across sessions

Budget Management

  • Monthly Budgets — Set overall monthly spending limits with automatic tracking
  • Daily Targets — Break down monthly budgets into daily spending targets
  • Category Budgets — Assign specific limits to individual expense categories
  • Progress Monitoring — Visual indicators showing budget utilization percentage

Accounts & Transactions

  • Account Types — Bank accounts, credit cards, cash, savings, and digital wallets
  • Transaction Types — Income, expense, and transfer transactions
  • Payment Methods — Track payment method for each transaction
  • Transaction History — Complete history with search and filtering

Savings Goals

  • Goal Tracking — Create savings goals with target amounts and deadlines
  • Progress Visualization — Visual progress rings showing completion percentage
  • Contribution Logging — Record deposits and withdrawals against each goal
  • Multiple Goals — Track multiple savings goals simultaneously

Bills & Subscriptions

  • Subscription Tracker — Manage Netflix, gym, Wi-Fi, and other recurring expenses
  • Due Date Display — View upcoming bill due dates in the Bills tab
  • Payment Method Linking — Associate bills with specific accounts
  • Paid / Unpaid Toggle — Mark bills as paid for the current cycle
  • Default Presets — Pre-configured subscription presets for quick setup

Daily Planning

  • Habit Tracking — Track daily habits with streak monitoring
  • Time-of-Day Filtering — Morning, Afternoon, Evening, and Night habit segments
  • Streak Analytics — Consecutive-day tracking and completion rates
  • Priority Tasks — Daily to-do items with Urgent, High, Medium, Low priority levels
  • Task Management — Due dates, completion toggles, and category labels

Routines & Habits

  • Custom Routines — Create personalized daily routines
  • Flexible Scheduling — Set specific days of the week for each routine
  • Completion Tracking — Mark routines complete and track consistency
  • Streak Motivation — Visual streak indicators to encourage consistency

Analytics & Insights

  • DayFlow Score — A 0–100 wellness score evaluating financial and habit discipline
  • Category Analysis — Category breakdown showing spending distribution
  • Budget Utilization — Track budget vs. actual spending across categories
  • Achievement Badges — Milestone badges unlocked by completing routines and streaks
  • On-Device Intelligence — Rule-based financial insights generated locally, no API required

Backup & Restore

  • JSON Backup — Complete database backup in schema-versioned JSON format
  • JSON Restore — Restore from backup with schema version validation
  • CSV Export — Export transactions in standard CSV format for spreadsheet analysis
  • Offline Backup — All backup and restore operations work entirely offline

Security & Privacy

  • PIN Lock — 4-digit PIN security lock; PIN is stored as a SHA-256 hash, never in plain text
  • Attempt Throttling — Lock screen blocks input for 30 seconds after 5 consecutive wrong entries
  • Local Storage — 100% offline data storage with Room SQLite
  • No Cloud Dependencies — All data stored locally on device
  • Privacy First — No data collection or external tracking
  • Backup Exclusion — Room database and DataStore are excluded from Android Auto Backup by policy

Notifications

  • Notification Channels — Three dedicated channels: habit reminders, bill alerts, budget alerts
  • Android 13+ Support — Runtime POST_NOTIFICATIONS permission request on API 33+
  • Permission Graceful Denial — App continues to work normally if the user denies notification permission

Note on notification delivery: Notification channels are registered and the permission is requested. Scheduling of individual reminder notifications (AlarmManager / WorkManager triggers for specific bill due dates or habit times) is an extension point for buyers to implement based on their scheduling requirements.

Offline Functionality

  • 100% Offline — Complete functionality without internet connection
  • On-Device AI — Financial intelligence runs entirely on-device
  • No Server Costs — No backend infrastructure or recurring costs
  • Reliable Performance — Consistent performance regardless of network conditions

Starter Templates

  • Blueprint Packs — Pre-configured habit and budget templates installed in one tap
  • Millionaire Morning — High-performance morning routine template
  • 50/30/20 Wealth — Budget template based on the popular budgeting rule

Optional AI Integration

On-Device Financial Intelligence — DayFlow includes built-in, rule-based financial insights that work completely offline:

  • Budget pace analysis and warnings
  • Savings rate calculations from income vs. expense
  • Goal proximity tracking
  • Habit consistency monitoring
  • Spending pattern detection

All local insights work 100% offline without requiring any external services or API keys. The insight engine is provided via an AIProvider interface — buyers can swap in a cloud AI provider by implementing the interface and calling AIService.setProvider().

Optional Cloud AI Integration — DayFlow includes a pluggable AIProvider interface for connecting third-party AI providers:

  • API Credentials Required — Cloud AI connectivity requires the buyer to configure their own API credentials
  • API Costs — Third-party AI services may charge separately for API usage; costs are not included with this item
  • No Cloud Client Shipped — No Gemini, OpenAI, or other cloud AI client is included; buyers implement their own using the AIProvider interface

Technology Stack

  • UI Framework: Jetpack Compose + Material Design 3

  • Local Persistence: Room Database (SQLite) version 4 — entities use Double for monetary amounts; the included Money.kt value object is available for precision arithmetic in business logic

Architecture

DayFlow follows modern Android architecture best practices:

  • MVVM Architecture — Model-View-ViewModel separation of concerns
  • Repository Pattern — Single source of truth for all data operations (DayFlowRepository)
  • Room Database — Type-safe local SQLite with compile-time query verification; version 4 with explicit migrations
  • DataStore Preferences — Persistent storage for user preferences (currency, theme, PIN hash, notifications)
  • Kotlin Coroutines & Flow — Reactive data streams and async operations
  • Jetpack Compose — Declarative UI with Material Design 3
  • Lifecycle-Aware Components — Efficient state management with collectAsStateWithLifecycle

Customization

DayFlow is designed for easy customization — all configurable values are centralized in AppConfig.kt:

  • App Name & Slogan — APP_NAME, APP_SLOGAN in AppConfig; launcher label in strings.xml
  • Application ID — Change applicationId in app/build.gradle.kts and APPLICATION_ID in AppConfig before publishing
  • Default Currency — DEFAULT_CURRENCY_SYMBOL and DEFAULT_CURRENCY_CODE
  • Supported Currencies — Add or remove entries from SUPPORTED_CURRENCIES list
  • Default Categories — Edit DEFAULT_CUSTOM_CATEGORIES list; seeded once on first install
  • Feature Flags — 10 boolean flags (AI, PIN lock, export, paywall, blueprints, etc.)
  • Play Billing IDs — PLAY_STORE_PRO_* product ID placeholders
  • Support & Legal URLs — SUPPORT_EMAIL, PRIVACY_POLICY_URL, TERMS_OF_SERVICE_URL
  • Theme Colors — Edit ui/theme/Color.kt; dark and light schemes both defined

See documentation/APPCONFIG.md for a complete field-by-field reference with examples.

Installation

  1. Extract the downloaded source code archive
  2. Open Android Studio (Hedgehog or later) and select Open to navigate to the project folder containing settings.gradle.kts
  3. Wait for Gradle sync to complete (first sync downloads dependencies)
  4. Connect an Android device (API 24+) or create an emulator
  5. Click Run to build and launch the application

On first launch, demo data is seeded automatically so all UI sections are populated. Complete setup instructions are in documentation/GETTING_STARTED.md.

Billing Integration (Optional)

Google Play Billing is optional and not required for the application to function. All features work without any billing configuration.

  • NoOpBillingService — Default implementation; does not contact Google Play; all features available
  • GooglePlayBillingService — Template stub; wire the Google Play Billing Library to activate (see BILLING_SETUP.md)
  • BillingService interface — Clean abstraction; swap implementations without changing any UI or ViewModel code
  • No Credentials Included — No real API keys, product IDs, or merchant credentials in the source
  • Envato Independence — No Envato license check at runtime; ProFeatureManager always grants access

Complete billing setup instructions are in documentation/BILLING_SETUP.md.

Release Build

# Debug build (no keystore needed)
./gradlew assembleDebug

# Release APK (requires signing env vars — see RELEASE_BUILD.md)
./gradlew assembleRelease

# Release AAB for Google Play Store
./gradlew bundleRelease

R8 minification is enabled for release builds. ProGuard rules covering Room, Kotlin, Compose, DataStore, and app models are included in app/proguard-rules.pro.
